# Docs 模块指南

## 1. 模块概述

本目录存放项目文档，包括设计文档、API 文档、使用说明等。

## 2. AI 规则

1. 修改代码时，必须同步更新相关文档。
2. 文档应简洁、准确，避免复制粘贴大段代码。
3. 使用表格、列表等结构化方式呈现信息。
4. 目录结构：
   - `design.md`：架构设计
   - `api.md`：接口文档
   - `usage.md`：使用说明
   - `faq.md`：常见问题

## 3. 维护责任

| 文件 | 维护时机 |
|-----|---------|
| `design.md` | 架构变更 |
| `api.md` | 接口变更 |
| `usage.md` | 使用方式变更 |
| `faq.md` | 发现常见问题时 |
