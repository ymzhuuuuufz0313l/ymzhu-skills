# {PROJECT_NAME}/markdown 文档子目录指南

## 1. 子目录概述

本目录为 **文档/分析子目录**，属于 `{PROJECT_PATH}` 项目子模块的一部分。

## 2. 目录内容

- 代码分析文档
- 验证计划
- 接口/寄存器/状态机说明
- 设计 review 记录

## 3. AI 规则

1. 修改本目录下文件前，先阅读本文件和父目录 `AGENTS.md`。
2. 文档应简洁、准确，避免复制粘贴大段代码。
3. 修改 `hdl/` 或 `test/` 中代码时，必须同步检查并更新本目录中的相关文档。
4. 新增文档时，在父目录 `AGENTS.md` 的"文档索引"章节补充说明。
5. 每次修改后，变更记录统一写入**父目录根级的 `CHANGES.md`**。

## 4. 维护责任

| 文件 | 维护时机 |
|-----|---------|
| 父目录 `AGENTS.md` | 文档索引变更 |
| 父目录 `CHANGES.md` | 每次文件修改后 |
| 代码分析文档 | hdl/test 代码变更后 |
| 验证计划 | test 用例/环境变更后 |
| 接口/寄存器说明 | hdl 接口/寄存器变更后 |
