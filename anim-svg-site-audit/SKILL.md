# 双版 SVG 站点审计协议（anim-svg-site-audit）

> 起源：2026-11-17/18 对 `team-share-public` 四个站点（longcode-420b / synthesis-postpt / lc-cpuwr-history / 根站）的全量只读审计。
> 本 skill 只管**审计与体检**：查什么、怎么查、怎么报。画风与生成规则在 `blueprint-ui-style`（本 skill 是它的体检表）。

## 0. 铁律

1. **审计期间只读**：审计会话不改文件、不跑 `--write`、不跑 `--commit`。发现的问题写进报告，改由另一轮（或另一成员）执行。历史事故：审计成员在 DRIFT 态跑 `--write`，覆盖了线上 `power_module_compare_1v11_1v22.svg`。
2. **不虚构**：结论必须能指到文件+行号/字节/md5。无法判定写 `[待确认]` 并说明缺什么证据。
3. **绝不为"整齐"删图**：图只归档、永不删除（用户硬规则）。
4. **上下文纪律**：大文件切片读（≤200 行/次），聚合统计用脚本而不是整文件读，禁止整站 cat、禁止把大 PNG 读进上下文。

## 1. 审计维度 A0–A9（逐项都要给结论：PASS / FAIL / N/A + 证据）

| # | 维度 | 怎么查 | 判红条件 |
|---|---|---|---|
| A0 | 站点清单 | 列 `*/images/*.svg`、`anim/*.svg`、`*.html` 引用，统计"被引用但不存在 / 存在但无引用" | 任一孤儿/断链 |
| A1 | 双版成对 | 每个 `anim/x.svg` 有同名静态 `x.svg`；`<text>` 多重集与静态版一致 | 缺静态版 / 文本多重集不等 |
| A2 | 图↔数据源 | 图内每个数字在生成器输入里指名；跑生成器 `--out` 与线上 `cmp` | 数字无来源 / 不可重生成 / md5 不一致 |
| A3 | 图↔正文 | 同一量在页面正文、表格、图里三种表示是否一致（含单位、精度、组数） | 同一量两种写法（如 18969/18970） |
| A4 | 组成图自洽 | Σ片 == 中心值；百分比分母 == 中心值；残差片显式登记 | 求和不等 / 分母错 / 负残差 |
| A5 | 缓存串 | 页面里 `?v=` 是否 ≥ 该图最后一次改动 | 图改了 `?v=` 没 bump |
| A6 | 索引同源 | `search-index.json` 与 `.js` 是否同一脚本产出、页面实际加载哪份、条目数与站点章节数是否对得上 | 两副本漂移 / 数量对不上 |
| A7 | 归档可追溯 | 每次换版有日期快照；同名快照未被覆盖；快照 md5 可验证 | 历史缺失 / 同名覆盖 |
| A8 | 文件卫生 | LF/CRLF、尾签名唯一且时间真实、无内部标识泄漏（内部路径/内部代号语义） | 双签名 / 未来时间签名 / 泄漏 |
| A9 | 门质量 | 每道自检脚本做"有牙三连"：注入错→必红；空集→必 FAIL；改一处→定位准 | 假绿 / 假红 / 无牙 |

## 2. 环外交叉验证（防"自证清白"）

- **不信任生成器自报**：图的数字要和**页面正文独立抽取**的结果比，不和生成器自己的中间变量比。
- **不信任单一脚本**：Σ片==中心值 至少用两条独立路径算（按数据源分组求和 / 按 SVG 里 `<text>` 抽数值求和）。
- **不信任"上次验过"**：刚修过的项按新项处理，不同维度的 ✓ 不互相传染（同 `subagent-dispatch` §汇总纪律）。

## 3. 六类病态清单（看到就记，别只记个案）

1. **门自己会撒谎**：假绿（空集恒真、相对 cwd 扫 0 文件、0 动画也算 PASS）、假红（print 与 exit 不一致，如 `↔` 编码错）、无牙断言（残差片自吸收）。
2. **口径双表示**：一个量两处写、两套求和、两套分母、数据层"展示值"字段与主字段并存。
3. **不可复现**：图无生成器（正则补丁线上 blob）、生成器硬编码绝对输出路径、无 `--out/--check`、逐行手调几何覆盖。
4. **归档受损**：同名快照覆盖、该有快照没有、只有 EOL 差异时无法复原原 blob。
5. **卫生**：裸 `write_text` 造成整文件 CRLF、尾签名正则锚在字符串尾而骨架签名在 `</html>` 前 → 稳定双签名、`?v=` 不 bump、内部标识泄漏。
6. **协作串改**：多人/多成员同时改同一 HTML/图、`git add -A` 把别人的暂存一起提交、成员在审计任务里跑了写模式。

## 4. 报告模板（审计产出就这一份，不写散文）

```markdown
# <站点> 图/数据一致性审计 <YYYY-MM-DD>

## 结论
- 站点：<路径>（HEAD <sha>）
- 图：N 张（静态 N1 / 动画 N2 / PNG N3），被引用 M 张，孤儿 K 张
- 红项：X 个（blocker a / high b / medium c / low d）

## 逐项
| # | 维度 | 结论 | 证据（文件:行 / md5 / 命令输出摘要） |

## 红项明细
| id | 严重度 | 现象 | 根因 | 建议修法（改生成器/改数据源/改页面） | 需用户拍板？ |

## 待确认
- [待确认] <现象> —— 缺 <证据类型>，建议 <获取方式>
```

severity 口径：**blocker** = 图与正文/数据矛盾且已对外可见；**high** = 口径不一致但当前未显示；**medium** = 可复现性/卫生缺口；**low** = 一致性打磨。
