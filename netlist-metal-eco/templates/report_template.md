## 1. 场景与判据（先说清 methodology 的坑）

- 金属层 ECO 唯一开关 = "有没有可被重连线的现存逻辑门"。
- **判据陷阱**：`输出网 0 负载` 只能抓完全无扇出的网，**抓不到"输出喂进死锥"的门**
  （某门输出有负载喂给下一级，但下一级输出无人使用 → 整锥功能死）。
- 本报告用 **死锥分析**：0 负载粗筛 → 迭代死锥收敛 → 跨模块逐字 grep → RTL 常量残骸佐证。

## 3. 三步改线方案 + 极性/驱动闸门

### 3.0 **极性判定（最关键、最容易错）**
> `.RB` 是低有效复位（net=0 才复位）。先把目标写成"该 net 应取的值"，再选门。

| 目标信号（net 应取的值） | 正确单门 | 函数 | 说明 |
|---|---|---|---|
| 驱动 `.RB`（低有效），净 = `A & ~B`（1=正常，0=复位） | **AND2B1** | `O = I1 & ~B2` | 零反相器；I1=A, B2=B |
| 同上，但只有 NAND2B1 可用 | NAND2B1 + 反相级 | `O = ~(A & ~B)` | 输出是反相值，**必须补一级反相**（死锥内 NAND2/INV），否则复位极性反了 |
| 正逻辑 `A & ~B` 中间使能 | **AND2B1** | `O = I1 & ~B2` | 直接 |
| 正逻辑 `~(A & ~B)` | **NAND2B1** | `O = ~(I1 & ~B2)` | 直接 |

**判定方法（按序）**：
1. 先确定接收端是什么：低有效复位 `.RB`/`.SB`？高有效使能？正/负逻辑？
2. 写出该 net 的**目标真值**：复位条件（net=0 的那些输入组合）。
3. 对照上表选单元；**NAND2B1 输出恒为 `~(A & ~B)`**，与 `A & ~B` 差一次反相。
4. 实证背书：若网表里已有同类实现（如某 `RSTN = A & ~B` 由 AND2B1 实现并驱动多个 `.RB`），
   直接以它为钢印，不靠猜。

### 3.1 三步改线
1. `.I1` ← 复位网（模块内现成）
2. `.B2` ← 错误条件网（B2 是反相输入，`~B2` 已含取反）
3. 目标 flop 的 `.RB` 从原网改接到<b>极性校正后</b>的门输出

### 3.2 驱动 / 时序闸门
- 替代门若是 **X1 弱驱动**，带 N 个 `.RB` 大概率 transition/cap 超标 → **必须先 PT 复核**
  （recovery/removal + transition，10 corner）。原树常是 `BUFX2→BUFX3`。
- 若金属层内无 buffer 可借 → 退**全层 ECO**（新增 AND2B1X4 + buffer）或改 RTL 重综合。

## 4. 功能风险 checklist（该不该做）

- [ ] 电平信号挂异步复位 → **正反馈钳死**（计数器钳 0 后 `==1` 判定永不到达？）
- [ ] 装载被吞（KEY_RST 在错误期被复位吞掉，丢帧？）
- [ ] 组合输出毛刺 → 假异步复位
- [ ] release recovery/removal 违例
- [ ] DFT 洁净复位规则（ATPG 可控性）被破坏
- [ ] "改机制 ≠ 照抄"（原来是打拍取沿脉冲，新版是电平挂异步 RB？）
